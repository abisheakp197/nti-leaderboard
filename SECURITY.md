# Security Policy

## Supported Versions

We actively maintain and patch the latest deployed version of the NTI Leaderboard. 

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Scope

This repository serves as the public-facing compliance dashboard for the NTI ecosystem. It renders static JSON data generated by the `nti-registry` and `nti-scanner`. 

We are specifically interested in vulnerabilities related to:
*   **Data Integrity:** Bypassing the UI verification logic to display a fake "Verified" badge or tampering with the `leaderboard.json` schema.
*   **Cross-Site Scripting (XSS):** Injecting malicious scripts via unescaped AST findings or framework names.
*   **Denial of Service (DoS):** Causing the client-side rendering to crash via malformed JSON payloads.
*   **Supply Chain:** Vulnerabilities in the Next.js dependencies or the build pipeline.

*Note: Disagreements regarding a framework's actual security score should be directed to the `nti-scanner` repository, not here.*

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Please report vulnerabilities directly to **abisheakp197@gmail.com**.

You should receive a response within 48 hours. If for some reason you do not, please follow up via email to ensure we received your original message.

Please include the following information in your report:
*   Type of issue (e.g., XSS, data spoofing, dependency vulnerability)
*   Full paths of source file(s) related to the manifestation of the issue
*   The location of the affected source code (tag/branch/commit or direct URL)
*   Any special configuration required to reproduce the issue
*   Step-by-step instructions to reproduce the issue

We will investigate all legitimate reports and do our best to quickly fix the problem.
